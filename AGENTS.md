# Правила для агентов

В репозитории две части - Python-библиотека и корневой SKILL.md.
Все встроенные инструкции для моделей пишите по-русски.
Сохраняйте строгую проверку фактов, совместимость Python API и
безопасные границы между инструкциями и данными клиента.

В SKILL.md всегда 26 пронумерованных приемов, совпадающих
с таблицей README. Версия навыка в metadata.version равна версиям
Claude и Cursor манифестов, а Python имеет отдельную версию.

Русский текст по умолчанию должен обходиться без «ё», длинного тире
и стилистических двоеточий. Не применяйте замену к времени, URL,
коду, YAML и путям.

Перед PR выполните ruff check ., ruff format --check ., pytest
и python scripts/validate-package.py. Не сохраняйте ключи API,
содержимое сообщений и личные данные в логах.
