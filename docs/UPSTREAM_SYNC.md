# Перенос upstream Humanizer

Источник blader/humanizer, релиз v4.0.0 от 10 ноября 2026,
коммит b48c832f0f809c1b5658edbb838c2521b72f2413.
Наша исходная ветка main -
25a79ee6c9c5c14996be1b83d2412c825fdb244b.

Репозитории разошлись на 47 upstream-коммитов и 26 своих
до этой работы. Прямой merge уничтожил бы нашу Python-архитектуру.

Перенесены все 26 редакторских приемов из шести разделов
оригинала, приоритет голоса автора, работа с целым файлом,
защита от поддельных closing tags и системных сообщений,
обязательное сохранение чисел, имен, дат и взаимосвязей,
манифесты Claude Code, Cursor, Codex и pi.

Главное осознанное отличие - upstream v4 допускает добавление
известных истинных деталей. Для автономной переписки мы разрешаем
только факты, подтвержденные контекстом продукта.
Русские системные инструкции объединены с Python-планировщиком.
Английский, испанский и китайский оставлены для совместимости API.

Эвристические проверки фактов не гарантируют истину. Без
актуального доверенного расписания и резюме продукт не должен
обещать свободные слоты или приписывать кандидату достижения.

Оригинал https://github.com/blader/humanizer (MIT).
