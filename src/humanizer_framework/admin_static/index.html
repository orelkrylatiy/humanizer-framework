Как обрабатываются данные

          

            
Текст генерации
Передается выбранному LLM-провайдеру. Не сохраняется админкой.

            
Техническая история
JSONL-телеметрия содержит статус, режим, длительность, провайдера и коды проверок, но не тексты.

            
Ключи
Читаются из переменных окружения или .env. Значения ключей не возвращаются интерфейсу.
